Student Record Management System:

Project Overview:-

The Student Record Management System is a menu-driven application developed using C programming. It uses multiple source files to perform different student record operations. The project demonstrates the concept of modular programming in C.

Objective:-

To develop a Student Record Management System by combining multiple C source files into a single executable program.

Features:-

Add (A/a): Add a new student record.

Delete (D/d): Delete an existing student record.

Show (S/s): Display the list of student records.

Modify (M/m): Modify student details.

Save (V/v): Save student records to a file.

Sort (T/t): Sort student records.

Exit (E/e): Exit the application.
